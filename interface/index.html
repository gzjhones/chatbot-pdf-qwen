📄 PDF Analyzer Widget — Demo

Esta página demuestra el widget embebido. Haz clic en el botón azul de la esquina inferior derecha para abrirlo.

Para embeber el widget en cualquier página HTML añade únicamente:

<script src="pdf-analyzer-widget.js"></script>

El widget:

  • Se inyecta automáticamente como botón flotante
  • Abre un panel con drag & drop de PDF
  • Solo acepta archivos .pdf
  • Muestra resultados en tarjetas: Objetivos, Conclusiones, Valoración
  • Usa Shadow DOM — no interfiere con los estilos de esta página
⚙️ Requiere que el servidor Flask esté corriendo:
python server/app.py  →  http://localhost:5050
